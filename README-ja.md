## タグ

各項目が何かを示しています。横のタグは選ぶ助けになります。公式は標準を定める側から出ているもの、オープンソースはコードが公開されているもの、無料か有料かは利用モデルによるもの、APIとSDKは統合の方法によるものです。「作者によるもの」のタグが付いた項目は Ciro Cesar Maciel が作成したもので、他のすべての項目と同じルールに従います。
