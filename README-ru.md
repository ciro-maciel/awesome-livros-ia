## Для начала

Что должен знать каждый, прежде чем использовать ИИ на работе.

- [IA no dia a dia (vol. 1)](https://go.mymarketing.click/livia-ia-no-dia-a-dia-vol-1) - Что должен знать каждый об искусственном интеллекте, чтобы работать. `платный` `от автора`
- [IA por dentro (vol. 2)](https://go.mymarketing.click/livia-ia-por-dentro-vol-2) - Как устроены машины, которые ведут диалог. `платный` `от автора`

## По профессии

Набор по каждой профессии: ежедневные задачи и нормы отрасли. У каждого есть открытый онлайн-набор.

- [IA no escritório (vol. 3)](https://go.mymarketing.click/livia-ia-no-escritorio-vol-3) - Для секретарей, ассистентов и административных помощников. `платный` `от автора`
- [IA no primeiro trabalho (vol. 4)](https://go.mymarketing.click/livia-ia-no-primeiro-trabalho-vol-4) - От вакансии до первой зарплатной ведомости для тех, кто только начинает. `платный` `от автора`
- [IA no pequeno negócio (vol. 5)](https://go.mymarketing.click/livia-ia-no-pequeno-negocio-vol-5) - От WhatsApp до кассы для MEI и малого предпринимателя. `платный` `от автора`
- [IA no atendimento e nas vendas (vol. 6)](https://go.mymarketing.click/livia-ia-no-atendimento-e-nas-vendas-vol) - Для продавцов, кассиров, администраторов и операторов телемаркетинга. `платный` `от автора`
- [IA na sala de aula (vol. 7)](https://go.mymarketing.click/livia-ia-na-sala-de-aula-vol-7) - Для преподавателей: план урока, проверка, адаптированное задание и отзыв без раскрытия личности ученика. `платный` `от автора`
- [IA na contabilidade (vol. 8)](https://go.mymarketing.click/livia-ia-na-contabilidade-vol-8) - Для бухгалтеров, техников и помощников: от выписки до DCTFWeb без раскрытия данных клиента. `платный` `от автора`
- [IA na advocacia (vol. 9)](https://go.mymarketing.click/livia-ia-na-advocacia-vol-9) - Для юристов: ходатайство, судебная практика и сроки без поддельных решений и без раскрытия клиента. `платный` `от автора`

## Для тех, кто создаёт

Системы, продукты и компании, построенные на ИИ-агентах.

- [Construir com IA (vol. 10)](https://go.mymarketing.click/livia-construir-com-ia-vol-10) - От прототипа до работающей системы: вход, данные и оплата для тех, кто создаёт, не умея программировать. `платный` `от автора`
- [Feito para agentes (vol. 11)](https://go.mymarketing.click/livia-feito-para-agentes-vol-11) - Как сделать так, чтобы ИИ-агент вашего клиента работал с вашим продуктом: сервер MCP, llms.txt и авторизация. `платный` `от автора`
- [A empresa de uma pessoa (vol. 12)](https://go.mymarketing.click/livia-a-empresa-de-uma-pessoa-vol-12) - One Person Business: как создать и вести весь бизнес с ИИ-агентами. `платный` `от автора`
- [Do primeiro visitante ao cliente (vol. 13)](https://go.mymarketing.click/livia-do-primeiro-visitante-ao-cliente-v) - Как с помощью ИИ-агентов построить витрину, привлечение клиентов и работу с ними в вашем бизнесе. `платный` `от автора`
- [Forward Deployed Engineer (vol. 14)](https://go.mymarketing.click/livia-forward-deployed-engineer-vol-14) - Как стать инженером, который переводит ИИ от пилотного проекта к производству. `платный` `от автора`

## Метки

Каждый пункт говорит, что он собой представляет. Метки рядом помогают выбрать: официальный, когда исходит от того, кто задаёт стандарт; открытый код, когда код опубликован; бесплатно или платно по модели использования; API и SDK по способу интеграции. Пункты с меткой "от автора" сделаны Сиро Сезаром Масиэлом и подчиняются тем же правилам, что и все остальные.
